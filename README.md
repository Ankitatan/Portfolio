## 🌌 Overview

**GAIverse** serves as the central hub for my analytics and machine learning body of work. Designed with a clean, modern aesthetic (custom radial gradients, glassmorphism, and responsive CSS grids), the site highlights end-to-end projects across retail forecasting, sentiment analysis, financial analytics, customer behavior segmentation, and interactive dashboards.

---

## ✨ Features & Architecture

* **Dynamic Project Deck:** Interactive, auto-advancing project carousel powered by vanilla JavaScript with touch/swipe gesture recognition and hover-pause mechanics.
* **Interactive Credentials Hub:** Mini carousel displaying verified training certifications with a full-screen image lightbox/zoom modal.
* **Responsive Multi-Device Layout:** CSS Grid and Flexbox scaffolding optimized across mobile, tablet, and widescreen viewports.
* **SEO & Social Structured Data:** Schema.org `Person` JSON-LD integration, Open Graph tags, and standard meta-architecture.
* **Zero Bloat & Fast Load:** Pure HTML5, CSS3, and Vanilla JavaScript with no external framework runtime dependencies.
